Signal flow

Four always-on Braids voices into a four-channel patchbay with feedback, out through one analogue jack and one USB capture endpoint. Everything here was taken from fm1_drone.cc's render loop rather than from the header comments — two of which disagreed with it.

1 · One voice

MONO overrides PAN; it does not sum into it. A voice is one signal until this stage — the insert slots deliberately exclude stereo effects — so MONO forces centre and ignores the pan knob. That becomes a sum-then-place chain only if a voice ever turns genuinely stereo.

2 · Four voices, the patchbay, two outputs

3 · Modulation

There is no key-synchronous modulation anywhere in this instrument. The drift free-runs with no reset entry point, the LFOs are shared so retriggering one would jolt the other three, and the envelope — the only per-voice thing that could be key-synced — is not a matrix source. "Press a key and have the filter open over twenty seconds" is impossible by construction, with F1 CUT sitting right there.

4 · How a value reaches the engine

The path an editor has to join, worth drawing apart from the audio. Every parameter carries three representations at once, and they are not redundant — they answer different questions.

For the editor: the device's parameters are natively 7-bit, so a CC is the parameter — not a lossy proxy for a wider internal value, which is what CC is on most synths. A plugin control maps 1:1 with no conversion layer. The exception is the handful above that carry a fine fraction, which is the argument for a SysEx path rather than 14-bit CC pairs.

5 · The parameter surface

70 per voice

MIDI channels 1–4. Oscillator, pitch, both filters, both slots, three EQ bands, envelope, level, pan, destination, and nine modulation depth/source pairs.

39 global

MIDI channel 16. Master, spread, Haas, the four effect channels with their routing, and the four LFOs.

One table

fm1_params.h declares the label, range, default, display unit and CC number once. The screen, the CC map, the patch bytes and the engine all read it, so they cannot drift apart.

6 · The screen's colour code

Worth carrying into the plugin, because it answers a question a number doesn't. A value becomes a colour on a thermal ramp — and a bipolar control is coloured by its distance from centre, so a pan at centre, an attenuverter at its detent and a modulation depth doing nothing all read cold.
